Тестовый проект для обработки файла с логом некоего приложения

Данный проект является CLI-приложением.
Основной модуль это log_parser.py принимающий один обязательный аргумент в виде относительного или абсолютного пути к файлу

Пример запуска:
python log_parser.py log.txt

Принимается, что в логах нужно находить вхождения INFO, WARNING и ERROR, а сама структура лога походит на:
"01.09.2026 ERROR Сообщение об ошибке"

Если требуется изменить шаблон поиска, то нужно внести изменения в модуле log_reader
